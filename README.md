### About Me

숙박 플랫폼 **꿀스테이**에서 CMS·PMS·파트너 앱·결제/인증 웹뷰 등 웹서비스 전 영역을 개발하고 있습니다. 본업과 병행하여, 팀 내 비효율을 발견하고 AI와 자동화로 해결하는 도구를 자발적으로 만들어왔습니다.

- 백엔드 API 문서가 없어 매번 사람에게 물어봐야 하는 병목을 해결하기 위해, 분석 파이프라인을 설계하고 사내 문서 사이트 + 검색 서버를 개발·배포
- 반복되는 개발 업무 4가지를 명령어 한 줄로 실행할 수 있는 자동화 스킬로 설계·구축
- 신규 웹 사업 방향을 검증하기 위해 실제 API에 연동된 프로토타입을 직접 만들어 경영진에게 제시
