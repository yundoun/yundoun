- CRM 응답에 들어 있는 고객 실명·연락처·주소·계좌가 확장 밖으로 나가지 않도록, 카드 계산에 필요한 값만 화이트리스트로 넘기고 이를 테스트로 고정
- 카드 표시 방식을 확장 재배포 없이 바꿀 수 있도록, 어드민에 카드 설정과 미리보기를 나란히 두는 위젯 화면을 구현
